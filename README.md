# Telegram Keyword Bot

A simple keyword-based Telegram bot with support for Hindi and English keywords.

## Features
- Responds to keywords like hello, price, help, bye (in both English and Hindi)
- Works using long polling (Render compatible)
- Easy to deploy

## Deployment
Set the environment variable `BOT_TOKEN` in Render.com, and use the start command:
```
python main.py
```
